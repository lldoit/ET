# 飘字效果系统实现计划

## 概述

使用DamageNumbersPro插件实现战斗飘字效果，支持正常伤害、暴击伤害和治疗三种类型。

---

## 技术方案

### DamageNumbersPro使用方式

```csharp
// 1. 加载预制体（DamageNumberGUI类型）
DamageNumberGUI prefab = Resources.Load<DamageNumberGUI>("DamageNumber/Normal");

// 2. 生成飘字
DamageNumber dn = prefab.Spawn(anchoredPosition, damageValue);

// 3. 设置父级Canvas
dn.SetAnchoredPosition(canvasTransform, screenPosition);
```

### 世界坐标转UI坐标

由于角色使用SpriteRenderer渲染，需要将世界坐标转换为UI坐标：

```csharp
// 世界坐标转屏幕坐标
Vector3 worldPos = character.transform.position;
Vector3 screenPos = Camera.main.WorldToScreenPoint(worldPos);

// 屏幕坐标转Canvas锚点坐标
RectTransformUtility.ScreenPointToLocalPointInRectangle(
    canvasRect, screenPos, uiCamera, out Vector2 anchoredPos);
```

```csharp
// 根据SpellResult判断飘字类型
bool isCrit = (damageInfo.SpellResult & (int)SpellResult.Crit) != 0;
bool isHeal = (damageInfo.SpellResult & (int)SpellResult.Heal) != 0;

DamageNumberComponent dnComponent = scene.GetComponent<DamageNumberComponent>();
if (isHeal)
    dnComponent.ShowHeal(targetWorldPos, damageInfo.Damage);
else if (isCrit)
    dnComponent.ShowCriticalDamage(targetWorldPos, damageInfo.Damage);
else
    dnComponent.ShowNormalDamage(targetWorldPos, damageInfo.Damage);
```

## 预制体配置

需要在Unity中创建3个DamageNumberGUI预制体：

| 预制体名称 | 颜色 | 字体大小 | 动画效果 |
|-----------|------|---------|---------|
| `DamageNumber_Normal` | 白色/黄色 | 正常 | 向上飘动消失 |
| `DamageNumber_Critical` | 红色/橙色 | 较大 | 放大弹跳+向上飘动 |
| `DamageNumber_Heal` | 绿色 | 正常 | 向上飘动消失 |

可以参考Demo/Prefabs/UI目录下的预制体：
- `Red Glow.prefab` - 可用作暴击模板
- `Pixel Heal.prefab` - 可用作治疗模板
- [Clear.prefab](file:///Users/lilei/Work/ET9_StateSync/Assets/Plugins/DamageNumbersPro/Demo/Prefabs/UI/Clear.prefab) - 可用作正常伤害模板
