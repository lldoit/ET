# 增强百度批量翻译工具

## 背景

当前工程已经接入 `cn.etetet.yiuilocalization`，并把 I2 原 Google 翻译后端替换为百度翻译。现有能力主要覆盖 I2 Editor 原生翻译入口，缺少面向项目语言表的批量补全、语言码校验和失败统计。

## 目标

- 在 YIUI 多语言工具中增加百度批量翻译入口。
- 默认只翻译目标语言的空白文本，避免覆盖人工翻译。
- 支持翻译前统计待翻译项，不调用百度接口、不写入资产。
- 翻译前校验百度 App ID、Secret Key、源语言、目标语言和百度语言码映射；语言码校验本身不依赖密钥。
- 翻译时跳过非文本 Term、空源文案和含 I2 specialization 的复杂文案。
- 输出已翻译、预计请求、预计字符、跳过和失败明细，便于定位问题。

## 非目标

- 不恢复 Prefab 多语言绑定 Key 扫描。
- 不输出策划/翻译审核表格。
- 不新增独立运行时多语言系统。
- 不保存百度密钥到仓库。

## 成功标准

- Unity 编译无错误。
- YIUI 多语言工具可选择源语言和目标语言。
- 工具能校验 `Chinese -> English` 的百度语言码映射。
- 工具能预检待翻译项，并统计预计请求数和字符数。
- 无百度配置时能明确提示，不发起翻译请求。
- 翻译结果写回 I2 Editor 语言源，并标记为 `AutoTranslated`。
