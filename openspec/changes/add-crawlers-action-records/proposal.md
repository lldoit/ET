# 增加 Crawlers 战斗行动记录

## 背景

`cn.etetet.crawlers` 已完成 P0 规则测试闭环，并支持敌人 `Attack`、`Defence`、`Summon`、`Poison`、`Disrupt`、Boss `Chant` 等结算。当前 UI 和调试逻辑只能读取最终状态或日志文本，无法结构化知道本次出牌、敌方回合和结算过程中发生了哪些关键行动。

后续要做敌人血条变化、护盾飘字、召唤表现、灵力扰乱提示、回合结算面板和 UI 数据绑定，需要规则层先产出稳定的结构化行动记录。

## 目标

- 在 `CrawlerBattleComponent` 上保存最近一次战斗阶段产生的行动记录。
- 出牌成功时记录卡牌、伤害、护盾、抽牌、回蓝、连段和破势结果。
- 敌方回合时记录攻击、防御、召唤、中毒、扰乱、吟唱伤害和最终玩家受伤。
- 战斗胜利或失败时记录结算结果。
- 扩展 `Crawlers_CombatRules_Test` 验证行动记录的关键字段。

## 非目标

- 不做动画队列。
- 不做跨回合完整 replay 历史。
- 不改网络同步、协议或持久化。
- 不改 YIUI prefab 或具体 UI 展示。
- 不新增 Luban 表结构。

## 成功标准

- 每次 `StartBattle` 清空旧行动记录。
- 成功出牌会追加 `PlayCard` 记录。
- 敌方回合会追加 `EnemyTurn` 记录。
- 胜利或失败会追加 `BattleEnd` 记录。
- 行动记录可通过测试读取并断言关键数值。
- `dotnet build ET.sln` 成功。
- `Test --Name=Crawlers_CombatRules` 成功。

## 风险

- 行动记录只保留最近运行态，不是长期日志；后续如果需要完整回放，需要独立设计历史容量和生命周期。
- 本阶段记录的是聚合结果，不记录每个敌人或每个目标的逐条动画步骤。
